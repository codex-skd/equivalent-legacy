<h2>v0.0.0-beta.24 - Curios Required + Slot Effects + Packaging Fix</h2>

<p>The arcana items now work while equipped, and a critical packaging bug is fixed.</p>

<h3>Changed</h3>
<ul>
<li><strong>Curios is now a required dependency</strong>: install <a href="https://www.curseforge.com/minecraft/mc-mods/curios">Curios</a> (15.0.0+ for MC 26.2) to use the mod. The arcana items (rings, bands, amulets, stones, talisman, watch) and all Klein Stars are equippable in Curios slots.</li>
<li><strong>Passive effects from Curios slots</strong>: regeneration, fire resistance, water breathing, saturation, speed, haste, slow falling, magnet, EMC absorption and auto-repair now apply while the item is <em>equipped</em> in a Curios slot (not only while it sits in your inventory).</li>
</ul>

<h3>Fixes</h3>
<ul>
<li><strong>Critical packaging fix</strong>: the generated <code>META-INF/neoforge.mods.toml</code> is now actually included in the built JAR. Previous releases shipped without the mod metadata and would not load when installed as a file; this release is the first that installs correctly.</li>
</ul>
