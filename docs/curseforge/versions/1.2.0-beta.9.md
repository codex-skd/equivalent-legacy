<h2>v1.2.0-beta.9 - Phase 4 Mob Farming System</h2>

<h3>Added</h3>
<ul>
<li><strong>Mob Farming Manager</strong>: Central registry for controlling spawner behavior (delay, spawn count, max nearby mobs)</li>
<li><strong>Spawner Control Wand</strong>: New item to link and configure creature spawners for automated farming</li>
<li><strong>Mind Stone Integration</strong>: Pedestals with Mind Stone auto-collect nearby XP orbs (16-block range)</li>
<li><strong>Black Hole Band Integration</strong>: Pedestals with Black Hole Band auto-collect nearby item drops</li>
<li><strong>Spawner Configuration</strong>: GUI screen for adjusting spawn delay (20-200 ticks), spawn count (1-8), and max nearby mobs (6-32)</li>
<li><strong>Server Tick Handler</strong>: Event listener for synchronized server-side mob farming operations</li>
<li><strong>Network Packets</strong>: Custom payload for spawner config sync and mob farming state synchronization</li>
<li><strong>Complete Localization</strong>: Added 11 new GUI and tooltip keys to all 18 language files</li>
</ul>

<h3>Technical Details</h3>
<ul>
<li><strong>NeoForge 26.2</strong>: Uses <code>ServerTickEvent</code> for server-side farming logic and <code>CustomPacketPayload</code> for network sync</li>
<li><strong>Mob Detection</strong>: 16-block AABB range for XP/item collection with efficient entity queries</li>
<li><strong>Pedestal Enhancement</strong>: New methods in <code>PedestalBlockEntity</code> for mob farming setup detection and collection</li>
<li><strong>Spawner Management</strong>: Supports up to 8 concurrent active spawners with independent configuration</li>
<li><strong>ItemEntity & ExperienceOrb Handling</strong>: Automatic collection and discard of entities in farming range</li>
</ul>

<h3>Usage</h3>
<ul>
<li><strong>Linking Spawners</strong>: Right-click a spawner with Spawner Control Wand (or Shift+Right-click to unlink)</li>
<li><strong>Configuring</strong>: Right-click linked spawner to open config GUI (set delay, count, max nearby)</li>
<li><strong>XP Collection</strong>: Place Mind Stone in Pedestal to auto-collect nearby XP (passive)</li>
<li><strong>Drop Collection</strong>: Place Black Hole Band in Pedestal to auto-collect nearby drops (passive)</li>
<li><strong>Detection Range</strong>: Both collection types work within 16 blocks of the pedestal (default)</li>
</ul>
