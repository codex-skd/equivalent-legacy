# Equivalent Legacy 1.3.0-beta.8 — Block Rendering & Translation Fixes

## 🐛 Bug Fixes

### Block Rendering
- **Fixed magenta/black texture placeholders** on key machines
  - Condenser MK1 & MK2
  - Alchemical Chest
  - Pedestals (Dark Matter, Red Matter)
- Applied proper 3D model geometry (parent: `base_chest`) replacing incomplete texture-only definitions
- All chest-like machines now render with correct visual hierarchy

### Translations
- **Fixed character encoding issues** in item/block tooltips
- **Corrected namespace mismatch** affecting all 19 language files
  - Updated 6,813+ translation keys from `projecte` → `equivalent_legacy` namespace
  - Items and blocks now display with proper localized names
- Verified all language files (en_us, es_es, and 17 others) for JSON validity and consistency

- 19 language translations

- Pedestal support with transmutation feedback
- Dark Matter & Red Matter furnace tiers
- Multi-chest network linking with shared EMC pools

This beta includes critical rendering and localization fixes that restore full UI functionality. All in-game names, tooltips, and visual feedback now work correctly.
