<h2>v1.0.2 - Fix items being consumed as crafting ingredients</h2>

<p>Bugfix release for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong>. No feature changes.</p>

<h3>Fixed</h3>
<ul>
<li><strong>Philosopher's Stone (and other tools) consumed by crafting</strong>: any recipe using
the Philosopher's Stone, Repair Talisman, Volcanite Amulet, Evertide Amulet, Arcana Ring or Zero
Ring as an ingredient consumed it instead of returning it to the crafting grid. The 1.21.1 port
dropped the crafting-remainder override these items rely on; restored via NeoForge's
<code>getCraftingRemainingItem(ItemStack)</code> / <code>hasCraftingRemainingItem(ItemStack)</code>,
returning the same stack (with its stored EMC/mode intact) instead of consuming it.</li>
</ul>
