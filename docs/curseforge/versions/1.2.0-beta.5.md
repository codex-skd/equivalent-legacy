<h2>v1.2.0-beta.5 - Phase 2.2 Custom Renderers Complete</h2>

<h3>Added</h3>
<ul>
<li><strong>PedestalRenderer</strong>: Custom BlockEntityRenderer for all 3 pedestals (base, DM, RM)</li>
<li><strong>Floating Items</strong>: Items display above pedestals with smooth animation</li>
<li><strong>Item Rotation</strong>: 360° rotation every 160 ticks + gentle bobbing motion</li>
<li><strong>Philosopher's Stone Glow</strong>: Special items have enhanced brightness</li>
<li><strong>TransmutationRenderingOverlay</strong>: HUD overlay showing nearby transmutable blocks</li>
<li><strong>EMC Cost Display</strong>: Overlay shows cost in EMC with color coding (green/red/gray)</li>
<li><strong>Performance Optimization</strong>: 20-tick cache for transmutation lookups (no per-frame recalculation)</li>
<li><strong>EquivalentLegacyRenderers</strong>: Central dispatcher registering all renderers via mod bus</li>
<li><strong>PedestalBlockEntity Helpers</strong>: `getItemRenderPos()` and `getItemRenderRotation()` for animation</li>
</ul>

<h3>Technical Details</h3>
<ul>
<li><strong>NeoForge 26.2.0.37-beta API</strong>: Uses new BlockEntityRenderer&lt;T,S&gt; with createRenderState/extractRenderState/submit pipeline</li>
<li><strong>GuiLayer Integration</strong>: Overlay registered via RegisterGuiLayersEvent</li>
<li><strong>Client-Side Only</strong>: All renderers marked with @OnlyIn(Dist.CLIENT)</li>
<li><strong>Smooth Animations</strong>: Floating position and rotation calculated from level.getGameTime()</li>
<li><strong>Memory Efficient</strong>: Proper PoseStack management (balanced push/pop)</li>
</ul>

<h3>Known Deviations from Plan</h3>
<ul>
<li><strong>ChestRenderer Deferred</strong>: Requires AlchemicalChestBlockEntity to implement LidBlockEntity and sync menu state — planned for future phase</li>
<li><strong>API Adaptation</strong>: Plan specified legacy rendering API; implemented to match actual NeoForge 26.2 APIs</li>
<li><strong>ClientEvents Integration</strong>: Folded into EquivalentLegacyRenderers to avoid duplicate subscriptions</li>
</ul>
