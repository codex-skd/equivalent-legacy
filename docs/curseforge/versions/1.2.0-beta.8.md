<h2>v1.2.0-beta.8 - Phase 3 Custom Transmutation GUI</h2>

<h3>Added</h3>
<ul>
<li><strong>Custom Transmutation GUI</strong>: Right-click Philosopher's Stone opens an interactive screen to browse and perform transmutations</li>
<li><strong>Scrollable Item List</strong>: 6-column grid showing all known transmutable items, sorted by EMC value (highest first); supports mouse wheel scrolling</li>
<li><strong>Click-to-Transmute</strong>: Click an item in the list to instantly transmute it (if affordable)</li>
<li><strong>EMC Display</strong>: Shows player's current EMC in the top-left corner of the GUI</li>
<li><strong>Affordability Indicator</strong>: Items the player cannot afford show a dark overlay; color changes based on available EMC</li>
<li><strong>Input/Output Slots</strong>: Display the selected item and transmutation result (visual feedback)</li>
<li><strong>Complete Localization</strong>: GUI keys added to all 18 language files (English, Spanish, German, French, Japanese, Chinese, etc.)</li>
</ul>

<h3>Technical Details</h3>
<ul>
<li><strong>NeoForge 26.2</strong>: Uses <code>AbstractContainerScreen&lt;TransmutationContainer&gt;</code> with <code>GuiGraphicsExtractor</code> for rendering</li>
<li><strong>PlayerKnowledge Integration</strong>: Reads known items from player's knowledge store, synced via <code>KnowledgeDataPayload</code></li>
<li><strong>State Synchronization</strong>: Server syncs player EMC and knowledge to client via network packets</li>
<li><strong>UI Layout</strong>: 202x194 screen with 6 columns × 4 rows visible (24 items per page)</li>
<li><strong>Rendering Pipeline</strong>: Uses <code>GuiGraphics.blit()</code> for background texture and <code>GuiGraphics.fakeItem()</code> for item rendering</li>
</ul>
