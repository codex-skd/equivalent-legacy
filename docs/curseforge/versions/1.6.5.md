<h2>v1.6.5 - Conditional custom conversions (ATM / Powah compat)</h2>

<p>Removes error-log noise on packs that do not ship All The Modium or Powah. No gameplay change.</p>

<h3>Changed</h3>
<ul>
<li><strong>Custom conversion files now honour NeoForge load conditions.</strong> <code>CustomConversionMapper</code> wraps its ops in <code>ConditionalOps</code> and parses each <code>pe_custom_conversions</code> file through <code>createConditionalCodecWithConditions</code>, the same pattern already used by the world-transmutation loader. A file whose <code>neoforge:conditions</code> are not met is skipped silently (debug log) instead of being force-loaded.</li>
<li><strong>Bundled ATM / Powah EMC compat is now gated.</strong> <code>atm_powah_compat.json</code> was split into <code>atm_compat.json</code> (gated behind <code>neoforge:mod_loaded</code> for <code>allthemodium</code>) and <code>powah_compat.json</code> (gated behind <code>neoforge:mod_loaded</code> for <code>powah</code>); the original file is kept empty for backwards compatibility. When neither mod is installed, the loader no longer logs a wall of <code>Unable to deserialize key: Registry minecraft:item does not contain element allthemodium:&hellip;</code> / <code>Failed to read conversions: &hellip; powah:&hellip;</code> errors on every EMC map. All EMC values and conversions are preserved unchanged for packs that do ship those mods.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>CustomConversionFile</code> &mdash; added <code>CONDITIONAL_CODEC = ConditionalOps.createConditionalCodecWithConditions(CODEC)</code>.</li>
<li><code>CustomConversionMapper.load(&hellip;)</code> &mdash; builds <code>new ConditionalOps&lt;&gt;(registryAccess.createSerializationContext(JsonOps.INSTANCE), ICondition.IContext.EMPTY)</code>, parses with <code>CONDITIONAL_CODEC</code>, merges <code>WithConditions::carrier</code>, and on an empty result logs <code>Skipping loading custom conversion file &hellip; as its conditions were not met</code> at debug.</li>
<li>New resources: <code>data/equivalent_legacy/pe_custom_conversions/atm_compat.json</code>, <code>&hellip;/powah_compat.json</code>; <code>&hellip;/atm_powah_compat.json</code> rewritten as an empty, double-gated placeholder.</li>
</ul>

<h3>Notes</h3>
<blockquote><code>./gradlew clean build</code> OK on both the 26.2 and 1.21.1 trees. Not verified in-game. Same change shipped for 1.21.1 as <code>0.0.0-beta.4</code>.</blockquote>
