<h2>v1.3.0-beta.5 - Alchemical Chest Network (Phase 6.1)</h2>

<h3>Beta Release: Connected Storage Networks</h3>
<p>Equivalent Legacy v1.3.0-beta.5 introduces <strong>Alchemical Chest Networking</strong> — link multiple chests together to share EMC storage and create advanced automation chains.</p>

<h3>Phase 6.1: Alchemical Chest Network ✅</h3>

<h4>New Features</h4>
<ul>
<li><strong>Chest Linking System</strong>
  <ul>
  <li>Red Matter Pedestal "Link" mode connects chests</li>
  <li>Up to 16 chests per network</li>
  <li>Visual indicators (particles/glow) when linked</li>
  <li>Automatic dimension persistence</li>
  </ul>
</li>
<li><strong>Network EMC Pool</strong>
  <ul>
  <li>All connected chests share EMC storage</li>
  <li>Draw from any chest, automatically balanced</li>
  <li>Real-time synchronization</li>
  <li>Master chest displays network status</li>
  </ul>
</li>
<li><strong>Network UI</strong>
  <ul>
  <li>Network status indicator in Alchemical Chest GUI</li>
  <li>Show total network EMC available</li>
  <li>List of connected chests</li>
  <li>Link/unlink management</li>
  </ul>
</li>
<li><strong>Automation Integration</strong>
  <ul>
  <li>Collectors feed into network pool</li>
  <li>Condensers draw from network pool</li>
  <li>Transmutation uses network EMC</li>
  <li>Seamless multi-machine workflows</li>
  </ul>
</li>
</ul>
