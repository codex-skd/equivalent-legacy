<h2>v1.6.1 - Ring Flight Rebalance</h2>

<h3>Fix</h3>
<ul>
<li><strong>Swiftwolf's Rending Gale and the Arcana Ring unintentionally granted creative flight</strong>: both rings gave the player the ability to fly (like in Creative mode) simply by carrying them, regardless of the ring's selected mode. Swiftwolf's Rending Gale did this while in the hotbar, offhand, or a Regalia Slots API ring slot, as long as it had at least 64 stored EMC; the Arcana Ring did this unconditionally in any slot, with no EMC or "active" requirement. This was deemed too powerful and unintended, so the flight grant has been removed from both items entirely. All their other mechanics (Swiftwolf's shield/lightning/mode cycling, Arcana's freeze/ignition/harvest/repel modes) are unaffected.</li>
</ul>
