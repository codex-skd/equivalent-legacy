<h2>v0.0.0-beta.11 - EMC Machines (Collectors, Relays, Condensers)</h2>

<p>EMC automation arrives: the three classic machines with block entities, GUIs and a simple neighbor-based EMC network.</p>

<h3>Added</h3>
<ul>
<li><strong>Collector MK1 / MK2 / MK3</strong>: generates EMC from skylight (4 / 12 / 40 EMC per second) and auto-charges a Klein Star in its slot.</li>
<li><strong>Relay MK1 / MK2 / MK3</strong>: pulls EMC from adjacent collectors into a large buffer (100k - 10M) and charges Klein Stars.</li>
<li><strong>Condenser MK1 / MK2</strong>: learns a target item from its input slot, drains EMC from a Klein Star and adjacent relays, and produces the target into its output.</li>
<li>Each machine has a GUI showing live EMC (and sun/progress for collectors), opening with a right-click.</li>
</ul>

<h3>Notes</h3>
<blockquote>Simplified versus ProjectE: the EMC network only links adjacent blocks (no chunk-based world network or upgrade system yet), and condensers produce into a single output slot. Still no alchemical bags/chest or Curios support.</blockquote>
