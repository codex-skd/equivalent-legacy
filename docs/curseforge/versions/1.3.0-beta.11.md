<h2>🐛 Bug Fix: Missing Item Models</h2>

<p>Fixed "Missing item model" warnings for pedestal, dark matter pedestal, red matter pedestal, alchemical chest, condenser mk1, and condenser mk2. These blocks all use the <code>base_chest</code> model with chest-style rendering.</p>

<h3>Root Cause</h3>
<p>The <code>particle</code> texture was defined in <code>base_chest.json</code> using a texture variable (<code>#chest</code>) that wasn't properly resolving in NeoForge's model validation. Moved the <code>particle</code> definition to each individual child model with explicit texture references.</p>
