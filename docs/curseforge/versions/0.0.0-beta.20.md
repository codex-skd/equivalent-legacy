<h2>v0.0.0-beta.20 - World-Level EMC Network</h2>

<p>Machines now share EMC across the whole dimension instead of only touching blocks.</p>

<h3>Changed</h3>
<ul>
<li><strong>Per-dimension EMC pool</strong>: a shared <code>EMCNetwork</code> lets Collectors, Relays and Condensers anywhere in the same dimension share EMC.</li>
<li><strong>Collectors</strong> generate EMC into the pool; <strong>Relays</strong> and <strong>Condensers</strong> draw from it (Klein Stars still charge/discharge through the pool).</li>
<li>Machine GUIs now show the network-wide EMC instead of a local buffer.</li>
</ul>

<h3>Notes</h3>
<blockquote>The pool is held in memory per dimension (not persisted across saves), and relays no longer have a distinct buffering role. This replaces the previous adjacent-block-only links.</blockquote>
