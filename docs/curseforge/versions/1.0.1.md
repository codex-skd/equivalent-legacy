<h2>v1.0.1 - Fix double-rendered alchemical chests</h2>

<p>Bugfix release for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong>. No feature changes.</p>

<h3>Fixed</h3>
<ul>
<li><strong>Alchemical Chest / Condenser / Condenser MK2 visual glitch</strong>: these blocks
render both a static baked chest model and their own animated lid model at the same time, so
from a distance (or mid-animation) they look like two chests superimposed &mdash; one stuck
closed, one opening. <code>AlchemicalChest#getRenderShape</code> returned
<code>RenderShape.MODEL</code> instead of <code>RenderShape.ENTITYBLOCK_ANIMATED</code>, so the
chunk renderer baked and drew the static model in addition to the block-entity renderer's
animated one. Now matches vanilla chest behaviour: only the animated model is drawn.</li>
</ul>
