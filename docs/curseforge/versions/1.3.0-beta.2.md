<h2>v1.3.0-beta.2 - Mob Farming System Complete</h2>

<h3>Beta Release: Automated Mob Farming</h3>
<p>Equivalent Legacy v1.3.0-beta.2 completes the <strong>mob farming system</strong> with full integration of spawner control and automatic resource collection.</p>

<h3>Phase 4: Mob Farming System ✅</h3>

<h4>New Features</h4>
<ul>
<li><strong>MobFarmingManager</strong>
  <ul>
  <li>Central manager for active spawners</li>
  <li>SpawnerState tracking (enabled, delay, count, maxNearby)</li>
  <li>Tick-based spawner updates</li>
  <li>Cooldown tracking for optimal performance</li>
  </ul>
</li>
<li><strong>MobFarmingTickHandler</strong>
  <ul>
  <li>ServerTickEvent integration</li>
  <li>FinalizeSpawnEvent synchronization with vanilla spawners</li>
  <li>Automatic XP and drop collection</li>
  </ul>
</li>
<li><strong>Pedestal Integration</strong>
  <ul>
  <li>Mind Stone → Automatic XP collection (converted to EMC)</li>
  <li>Black Hole Band → Automatic item drop collection (converted to EMC)</li>
  <li>Dark/Red Matter Pedestales → Spawner control (on/off, type, speed)</li>
  </ul>
</li>
<li><strong>EMC Conversion</strong>
  <ul>
  <li>All drops automatically converted to EMC via EMCHelper</li>
  <li>Seamless integration with EMC storage</li>
  <li>Configurable collection ranges (16 blocks default)</li>
  </ul>
</li>
</ul>
