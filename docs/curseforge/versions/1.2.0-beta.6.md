<h3>Integration Details</h3>

<strong>JEI Recipes</strong>:
- Category ID: `equivalent_legacy:transmutation`
- Recipe Type: `IRecipeDisplay`
- Displays: Input block (left) → Output block (right) | Cost: X EMC
- Supports: Forward lookup (click input) and reverse lookup (click output)

<strong>WTHIT Tooltips</strong>:
- Shows when hovering over transmutable blocks
- Format: `[Transmutable: Target Block Name]` + `Cost: X EMC`
- Color-coded (green/red/gray based on affordability)
- Server-safe: data synced via WTHIT packet system

<h3>How to Use</h3>

<strong>JEI (if installed)</strong>:
<ol>
<li>Open JEI overlay (default: R key)</li>
<li>Look for "Transmutation" category (new category)</li>
<li>Browse all available transmutation recipes</li>
<li>Click input or output blocks for bidirectional lookup</li>
<li>EMC cost displayed for each recipe</li>
</ol>

<strong>WTHIT (if installed)</strong>:
<ol>
<li>Enable WTHIT overlay (default key configurable)</li>
<li>Hover over any transmutable block (limestone → marble, etc.)</li>
<li>Tooltip shows: target block + EMC cost required</li>
<li>No configuration needed — works out of the box</li>
</ol>

<strong>Without JEI/WTHIT</strong>:
- Use `/eml transmute <block>` command to check transmutations
- Or interact with transmutation stones directly in world
- Full functionality unchanged
