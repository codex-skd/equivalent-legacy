<h2>v1.2.0-beta.6 - Phase 2.4 JEI/WTHIT Integration Complete</h2>

<h3>Added</h3>
<ul>
<li><strong>JEI Integration</strong>: New <em>Transmutation</em> recipe category (<code>equivalent_legacy:transmutation</code>) showing every block conversion with its EMC cost</li>
<li><strong>Recipe Layout</strong>: input block &rarr; arrow &rarr; output block, with the EMC cost drawn underneath (green "Free" for zero-cost conversions) and a hover tooltip</li>
<li><strong>Recipe Lookup</strong>: Philosopher's Stone and Transmutation Stone registered as crafting stations, so right-clicking them shows all transmutation recipes</li>
<li><strong>WTHIT/Jade Support</strong>: hovering a transmutable block adds <em>Transmutable: &lt;block&gt;</em> (gold) and <em>Cost: &lt;n&gt; EMC</em> (green when affordable, red when not, grey when free) to the tooltip</li>
<li><strong>Default Transmutation Recipes</strong>: ~90 built-in vanilla block mappings (stone family, dirt/sand/gravel, nether, end, woods, ores), reversible so both directions are browsable</li>
</ul>

<h3>Technical Details</h3>
<ul>
<li><strong>JEI 30.15.0.121</strong> for MC 26.2 (compatible with the pinned NeoForge 26.2.0.37-beta; 30.16+ requires a NeoForge bump)</li>
<li><strong>WTHIT 20.0.0</strong> (NeoForge) + Bad Packets 0.12.2, registered via <code>wthit_plugins.json</code> using the new <code>entrypoints</code> format and <code>IWailaClientPlugin</code></li>
<li><strong>Optional dependencies</strong>: declared as <code>compileOnly</code> + <code>localRuntime</code> and as <code>optional</code> in <code>neoforge.mods.toml</code> — the mod loads and works without JEI or WTHIT</li>
<li><strong>WorldTransmutationManager API</strong>: new helpers <code>isTransmutable</code>, <code>getTransmutation</code>, <code>getTransmutationMap</code> and a <code>TransmutationResult</code> record, plus <code>registerDefaultTransmutations()</code></li>
<li><strong>Localization</strong>: 6 new keys (<code>jei.equivalent_legacy.*</code>, <code>tooltip.equivalent_legacy.*</code>) added to all 18 language files</li>
</ul>

<h3>Known Deviations from Plan</h3>
<ul>
<li><strong>Dependency versions</strong>: the plan listed JEI 19.14.0 / WTHIT 11.7.1; the actual versions for MC 26.2 are JEI 30.x and WTHIT <code>neo-20.0.0</code></li>
<li><strong>Default recipe set added</strong>: Phase 2 shipped with an empty transmutation registry, so a curated default set of vanilla mappings was added to make the JEI/WTHIT features actually display content</li>
<li><strong>JEI API adaptation</strong>: plan described the legacy <code>IRecipeDisplay</code> API; implemented against the current <code>IRecipeCategory</code>/<code>IRecipeLayoutBuilder</code> API (non-deprecated <code>IRecipeType.create</code>, slot <code>add()</code>, <code>addCraftingStation</code>)</li>
<li><strong>WTHIT API adaptation</strong>: plan described the legacy <code>IDataProvider</code> + <code>IWthitPlugin</code>; implemented client-side via <code>IBlockComponentProvider</code> + <code>IWailaClientPlugin</code> (registry is static and client-available, no server data sync needed)</li>
</ul>
