<h2>v0.0.0-beta.27 - Startup Crash Fix</h2>

<p>Fixes the crash on launch on NeoForge 26.2.0.37-beta.</p>

<h3>Fixes</h3>
<ul>
<li>Removed the unused <code>NeoForge.EVENT_BUS.register(this)</code> call in the main mod class. The class has no <code>@SubscribeEvent</code> methods (all game-bus handlers live in <code>@EventBusSubscriber</code> classes), and newer NeoForge builds reject registering an object with no listener methods, aborting startup with <code>IllegalArgumentException</code>.</li>
</ul>
