<h2>Equivalent Legacy 1.4.2 &mdash; Server Crash Fix</h2>

<hr>

<h3>Fix</h3>

<ul>
<li><strong>Fixed a server crash triggered by corrupted block entity data.</strong> If a chunk retained stale block entity data for a block that was later replaced (e.g. an Enchanting Table broken and replaced with Nether Wart), scanning that area &mdash; such as the Stellar Condenser's death-drop collection &mdash; could throw an unhandled exception and crash the whole server tick. The scan now safely skips corrupted positions instead of crashing.</li>
</ul>

<hr>

<p><strong>Installation:</strong> Download and place in your mods folder.</p>
