<h2>v0.0.0-beta.28 - Registry ID Fix for NeoForge 26.2.0.37</h2>

<p>Fixes the server startup crash on NeoForge 26.2.0.37-beta.</p>

<h3>Fixes</h3>
<ul>
<li><strong>Item/Block registration</strong>: NeoForge 26.2.0.37-beta requires item and block constructors to run with their registry id already set. Migrated every registration to <code>registerItem</code> / <code>registerBlock</code> (and <code>registerSimpleBlockItem</code> for block items), which set the id via <code>properties.setId(...)</code> before construction. This fixes <code>Item id not set</code> / <code>Block id not set</code> / unbound-value startup failures.</li>
</ul>
