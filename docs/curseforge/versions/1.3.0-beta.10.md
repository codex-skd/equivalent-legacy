<h2>🐛 Critical Bug Fixes</h2>

<h3>Fixed GUI IndexOutOfBoundsException</h3>
<p>Opening Collector, Condenser, Relay, or Matter Furnace GUIs would rapidly accumulate duplicate data slots, causing <code>IndexOutOfBoundsException</code> crashes. The root cause was <code>PEContainer.broadcastPE()</code> calling <code>addDataSlot()</code> on every game tick. Fixed by removing the duplicate calls and properly initializing slots in constructors.</p>

<h3>Fixed Transmutation Table Blockstate</h3>
<p>The transmutation table blockstate JSON defined a <code>facing</code> property, but the Java block class had no such property registered. Added <code>EnumProperty&lt;Direction&gt; FACING</code> with <code>createBlockStateDefinition()</code>.</p>

<h3>Fixed Destruction Catalyst Blockstate</h3>
<p>The blockstate file was named <code>destruction_catalyst_block.json</code> but the block is registered as <code>destruction_catalyst</code>. Renamed for consistency.</p>

<h3>Fixed Missing Item Models & Textures</h3>
<ul>
<li><strong>spawner_control_wand</strong>: Broken parent path (<code>item/handheld</code> → <code>minecraft:item/handheld</code>)</li>
<li><strong>arcana_ring</strong>: Missing parent and textures in base model</li>
<li><strong>pe_axe, pe_pickaxe, pe_saw, transmutation_stone, spawner_control_wand</strong>: Missing texture PNGs — placeholder textures created</li>
</ul>

<h3>Fixed Missing Particle Textures</h3>
<p>Added <code>particle</code> texture entry to <code>base_chest.json</code>, fixing warnings on alchemical chest, pedestal, and condenser block models.</p>
