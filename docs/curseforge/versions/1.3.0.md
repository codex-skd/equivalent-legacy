<h2>v1.3.0 - Equivalent Legacy — Full Port Complete ✅</h2>

<h3>Production Release: Faithful NeoForge 26.2 Port</h3>
<p>Equivalent Legacy v1.3.0 is the <strong>complete, stable production release</strong> of the Equivox 26.1.2 mod faithfully ported to NeoForge 26.2 with all features fully functional and integrated.</p>

<h3>🎯 What's Included</h3>

<h4>✅ Phase 1: EMC & Container Infrastructure</h4>
<ul>
<li><strong>EMC Registry</strong> (Phase 1B)
  <ul>
  <li>235+ hardcoded EMC values (oak_log=2, diamond=2048, netherite_ingot=8192, etc.)</li>
  <li>Priority-based mapper system (FixedValues → RecipeMappers → DataComponentMappers → SpecialMappers → GraphMapper)</li>
  <li>Component processors: enchantments, damage, containers, armor trim, bundle, books</li>
  <li>Public API: EquivalentLegacyEMCAPI for custom conversions</li>
  </ul>
</li>
<li><strong>Container Menus</strong> (Phase 1A)
  <ul>
  <li>PEContainer abstract base with 64-bit EMC sync via BoxedLong</li>
  <li>ValidatedSlot and ValidatedContainerSlot with Predicate validators</li>
  <li>SlotGhost for display-only slots</li>
  <li>Collector, Condenser, Relay, Bag, Chest menu implementations</li>
  </ul>
</li>
<li><strong>Capability System</strong>
  <ul>
  <li>IEmcStorage: persistent EMC storage across block entities</li>
  <li>IKnowledgeProvider: transmutation knowledge per player</li>
  <li>IEmcProvider: EMC source integration</li>
  </ul>
</li>
</ul>

<h4>✅ Phase 2: Data Files & Localization</h4>
<ul>
<li><strong>Complete Data Package</strong> (142+ JSON files)
  <ul>
  <li>Recipes: all machines (collectors, condensers, relays, furnaces, chests, transmutation table)</li>
  <li>Loot tables: block drops for all unique blocks</li>
  <li>Tags: item and block grouping for crafting/processing</li>
  <li>Advancements: unlock progression tree</li>
  </ul>
</li>
<li><strong>19-Language Localization</strong>
  <ul>
  <li>Primary: English (en_us)</li>
  <li>Translated: Spanish (es_es), French (fr_fr), German (de_de), Italian (it_it), Portuguese (pt_br, pt_pt), Russian (ru_ru), Japanese (ja_jp), Chinese (zh_cn, zh_tw), Korean (ko_kr), Polish (pl_pl), Dutch (nl_nl), Swedish (sv_se), Norwegian (no_no), Finnish (fi_fi), Danish (da_dk), Turkish (tr_tr)</li>
  <li>100+ translatable keys (item names, block names, tooltips, messages, GUI labels)</li>
  <li>UTF-8 encoding, no BOM</li>
  </ul>
</li>
</ul>

<h4>✅ Phase 3: Transmutation System</h4>
<ul>
<li><strong>Transmutation GUI</strong>
  <ul>
  <li>Scrollable item list (9 items per page)</li>
  <li>Cost visualization: green (affordable) / red (insufficient EMC)</li>
  <li>Input/output slots for item transmutation</li>
  <li>EMC display and balance tracking</li>
  <li>Localized in all 19 languages</li>
  </ul>
</li>
<li><strong>Transmutation Table</strong>
  <ul>
  <li>Crafted from components</li>
  <li>Integrated with EMC registry for real-time pricing</li>
  <li>Player knowledge persistence (learned items per player)</li>
  </ul>
</li>
</ul>

<h4>✅ Phase 4: Mob Farming System</h4>
<ul>
<li><strong>MobFarmingManager</strong>
  <ul>
  <li>Automatic spawner detection (16-block range)</li>
  <li>SpawnerState tracking: enabled/disabled, spawn count, max nearby mobs</li>
  <li>Multi-dimensional spawner management</li>
  </ul>
</li>
<li><strong>Pedestal Integration</strong>
  <ul>
  <li><strong>Mind Stone</strong>: automatic XP orb collection</li>
  <li><strong>Black Hole Band</strong>: automatic item drop collection (converts to EMC)</li>
  <li><strong>Dark/Red Matter Pedestales</strong>: spawner control (enable/disable, type, speed)</li>
  </ul>
</li>
<li><strong>Automation Support</strong>
  <ul>
  <li>Mob drops → Black Hole Band → EMC pool</li>
  <li>XP orbs → Mind Stone → Player XP</li>
  <li>Full MobSpawnEvent integration with max-nearby enforcement</li>
  </ul>
</li>
</ul>

<h4>✅ Phase 5: Matter Furnace & Alchemical Chests</h4>

<strong>Matter Furnace</strong> (Phase 5.1)
<ul>
<li>Two variants: Dark Matter (efficiency 14, attack 3) and Red Matter (efficiency 16, attack 4)</li>
<li>19-slot inventory (1 fuel + 9 input + 9 output)</li>
<li>Cost modifier: Red Matter 80% cheaper than Dark Matter</li>
<li>EMC fuel via Klein Stars</li>
<li>Smelting progress indicator</li>
<li>Automatic item output</li>
</ul>

<strong>Alchemical Chests</strong> (Phase 5.2)
<ul>
<li>104-slot massive storage (8 rows × 13 columns)</li>
<li>10,000,000 EMC capacity per chest</li>
<li>Waterloggable & FACING-aware placement</li>
<li>Lid animation</li>
<li>IEmcStorage capability integration</li>
<li>Large 256×256 GUI for easy access</li>
</ul>

<h4>✅ Phase 6: Advanced Features</h4>

<strong>Alchemical Chest Network</strong> (Phase 6.1)
<ul>
<li><strong>Chest Linking</strong>
  <ul>
  <li>Red Matter Pedestal "Link" mode connects multiple chests</li>
  <li>Up to 16 chests per network</li>
  <li>Visual indicators (particles/glow) for linked chests</li>
  <li>Dimension-aware persistence</li>
  </ul>
</li>
<li><strong>Network EMC Pool</strong>
  <ul>
  <li>All connected chests share EMC storage</li>
  <li>Draw from any chest, automatically balanced</li>
  <li>Real-time EMC synchronization</li>
  <li>Master chest displays network status</li>
  </ul>
</li>
<li><strong>Automation Integration</strong>
  <ul>
  <li>Collectors → Network Pool → Condensers workflow</li>
  <li>Transmutation uses shared network EMC</li>
  <li>Mob farming drops feed into network</li>
  </ul>
</li>
</ul>

<h3>📦 Installation</h3>

1. Install Minecraft 26.2 + NeoForge 26.2.0.37-beta
2. Download Curios API 15.0.0-beta.2+26.2
3. Place equivalent_legacy-1.3.0.jar in mods/ folder
4. Launch game

<h3>🎮 Gameplay Features</h3>

- **EMC Economy**: Transmute items using EMC (Equivalent Matter Cost)
- **Automated Farming**: Spawner detection + pedestal integration for mob/item collection
- **Matter Crafting**: Dark and Red Matter furnaces with cost optimization
- **Advanced Storage**: Alchemical Chests (104 slots) with network linking
- **Mob Integration**: Automatic XP/drop collection with Mind Stone and Black Hole Band
- **Progression**: Transmutation knowledge system + advancement tree
