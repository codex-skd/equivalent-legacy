<h2>v1.2.0-beta.4 - World Transmutation & Phase 2 Complete</h2>

<h3>Added</h3>
<ul>
<li><strong>World Transmutation System</strong>: Right-click blocks with Philosopher's Stone or Transmutation Stone to transmute them</li>
<li><strong>WorldTransmutationManager</strong>: Core logic for block transmutation with EMC consumption/gain</li>
<li><strong>Block Transmutation</strong>: Convert blocks in the world (e.g., stone ↔ cobblestone, dirt ↔ grass)</li>
<li><strong>EMC Economy</strong>: EMC is consumed/gained based on block value differences</li>
<li><strong>API Events</strong>: WorldTransmutationEvent for addon integrations</li>
<li><strong>Pedestals (Base, DM, RM)</strong>: Blocks for item storage and display</li>
<li><strong>Nova Entities</strong>: 3 entity types (Nova, Catalyst, Cataclysm) with explosion mechanics</li>
<li><strong>PE Tools</strong>: Axe, Pickaxe, Saw with special properties</li>
<li><strong>Destruction Catalyst Block</strong>: Triggers nova explosions on activation</li>
<li><strong>Transmutation Stone Item</strong>: Alternative to Philosopher's Stone for transmutation</li>
<li><strong>Phase 1-2 Complete</strong>: All items, blocks, tools, and transmutation mechanics implemented</li>
</ul>

<h3>Changed</h3>
<ul>
<li>PlayerEvents extended: Added <code>onRightClickBlock</code> listener for transmutation detection</li>
<li>ServerConfig: Added transmutation options (enabled, cooldown, range)</li>
<li>EMC System: Integrated with world transmutation for balanced economy</li>
</ul>

<h3>Technical</h3>
<ul>
<li>42 new files added (blocks, entities, items, APIs, rendering stubs)</li>
<li>WorldTransmutationManager: Centralized transmutation policy and mechanics</li>
<li>Block entities for pedestals with inventory support</li>
<li>Public API interfaces: IEMCProvider, ITransmutationAllowed, IKnowledgeProvider, IEMCStorage, IEmcReceptor</li>
<li>Public events: WorldTransmutationEvent, EMCTransmutationEvent, EMCDiscoveryEvent</li>
<li>NeoForge 26.2.0.37-beta compatible</li>
</ul>
