<h2>v0.0.0-beta.29 - EMC Value Map Fix</h2>

<p>Fixes the startup crash during EMC value registration.</p>

<h3>Fixes</h3>
<ul>
<li><strong>EMC value maps</strong>: <code>FixedValues</code> and <code>CustomConversion</code> used sorted maps (<code>Object2LongRBTreeMap</code> / <code>Object2IntRBTreeMap</code>) that require <code>Comparable</code> keys, but <code>NSSItem</code> is not comparable — registering EMC values crashed at startup with <code>ClassCastException</code>. Switched to hash maps (<code>Object2LongOpenHashMap</code> / <code>Object2IntOpenHashMap</code>), which is all the iteration-based callers need.</li>
</ul>
