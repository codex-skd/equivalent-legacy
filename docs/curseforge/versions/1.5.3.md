<h2>v1.5.3 - Sharp Weapon Enchantments &amp; NeoForge Update</h2>

<h3>Fix</h3>
<ul>
<li><strong>Sharpness, Smite and Bane of Arthropods could not be applied to DM/RM swords and axes</strong>: <code>dm_sword</code>, <code>rm_sword</code>, <code>dm_axe</code>, <code>rm_axe</code> and <code>rm_katar</code> were explicitly excluded from the <code>minecraft:enchantable/sharp_weapon</code> tag since v1.5.0, leaving only <code>melee_weapon</code> enchantments (Knockback, Looting, Fire Aspect, Sweeping Edge) available on those weapons. The exclusion has been removed so the full <code>sharp_weapon</code> set applies too, consistent with <code>melee_weapon</code> already being re-added in v1.5.0.</li>
</ul>

<h3>Change</h3>
<ul>
<li><strong>NeoForge updated</strong>: from <code>26.2.0.45-beta</code> to <code>26.2.0.57</code>.</li>
</ul>
