<h2>v0.0.0-beta.3 - First item: Philosopher's Stone</h2>

<p>The mod now has its first piece of actual content: the Philosopher's Stone item, along with the item/block registration framework and the mod's own creative tab.</p>

<h3>Added</h3>
<ul>
<li><strong>Philosopher's Stone</strong>: first functional item, hooked into the existing EMC system for value lookups. Transmutation logic is not implemented yet.</li>
<li>Item and block deferred register framework (<code>EquivalentLegacyItems</code>, <code>EquivalentLegacyBlocks</code>).</li>
<li>Equivalent Legacy creative mode tab.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Fixed <code>archivesName</code> in <code>build.gradle</code> to follow the <code>&lt;mod_id&gt;-&lt;mc-version&gt;-neoforge</code> naming convention.</li>
</ul>

<h3>Notes</h3>
<blockquote>Still early development. No transmutation, GUI, networking, or commands yet.</blockquote>
