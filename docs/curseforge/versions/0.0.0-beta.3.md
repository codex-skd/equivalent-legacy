<h2>v0.0.0-beta.3 - Block item textures fix</h2>

<p>Maintenance beta for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong>. Client asset fix, no gameplay or code changes.</p>

<h3>Fixed</h3>
<ul>
<li><strong>Missing item textures on 19 block items.</strong> Minecraft 1.21.1 resolves item models from <code>assets/equivalent_legacy/models/item/&lt;id&gt;.json</code>. The 1.21.1 port produced those models for every standalone item but not for the block items, so the Alchemical Coal / Mobius Fuel / Aeternalis Fuel blocks, Collector MK1&ndash;3, Entropy Sink (all tiers), Stellar Condenser, Dark / Red Matter Furnace, Dark / Red Matter blocks, Nova Catalyst, Nova Cataclysm and Relay MK1&ndash;3 all rendered as the missing-texture checkerboard in the creative inventory and in hand. The 19 item models were added, each parenting its existing block model (the pattern already used by <code>dm_pedestal</code>, <code>interdiction_torch</code> and the chest-like blocks).</li>
</ul>

<h3>Notes</h3>
<blockquote>Beta. <code>./gradlew clean build</code> OK. Asset-only change on top of beta.2; no Java touched. The <code>assets/equivalent_legacy/items/</code> directory is the 1.21.4+ item-model-definition format and is ignored by 1.21.1. Not verified in-game.</blockquote>
