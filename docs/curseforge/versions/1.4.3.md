<h2>Equivalent Legacy 1.4.3 &mdash; Collector Fixes &amp; EMC Balance</h2>

<hr>

<h3>Fix</h3>

<ul>
<li><strong>Fixed a stray sprite bleeding outside the Collector MK1 GUI panel.</strong> The sun/fuel bar reference sprite packed into <code>collector1.png</code> sat right at the edge of the panel's declared width, so part of it rendered as a loose icon stuck to the corner of the panel. Moved it further into the texture on all three tiers.</li>
<li><strong>Fixed the item being charged disappearing when a Collector is broken.</strong> The block-break inventory drop reused the automation-facing handler, which intentionally blocks extracting the slot currently charging (so hoppers can't steal it) &mdash; that same restriction silently discarded the charging item when the block was mined.</li>
<li><strong>Fixed the Philosopher's Stone transmutation preview icon getting stuck on top of any open GUI</strong> (e.g. a Collector) if you opened it right after aiming the stone at a block.</li>
<li><strong>Fixed a few EMC values priced above their cheapest real recipe</strong> (<code>name_tag</code>, <code>andesite</code>, <code>moss_block</code>), which allowed generating free EMC by crafting and decomposing them.</li>
</ul>

<h3>Technical Changes</h3>

<ul>
<li>Removed <code>ThreadCheckUUID</code>, a legacy ProjectE-era thread that pinged a third-party GitHub repo on every server start.</li>
<li>Renamed the mod's entry point class from <code>PECore</code> to <code>ELCore</code> (no behavior change).</li>
</ul>

<hr>

<p><strong>Installation:</strong> Download and place in your mods folder.</p>
