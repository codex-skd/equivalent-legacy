<h2>v0.0.0-beta.17 - Misc Toolchain Items</h2>

<p>The remaining handheld tools of the original toolchain.</p>

<h3>Added</h3>
<ul>
<li><strong>Nova Catalyst / Nova Cataclysm</strong>: TNT-and-fuel crafting components.</li>
<li><strong>Divining Rods I-III</strong>: right-click a block to see the total EMC of the surrounding area (radius grows with tier).</li>
<li><strong>Destruction Catalyst</strong>: right-click to clear a 3x3x3 area (drops items).</li>
<li><strong>Hyperkinetic Lens</strong>: right-click creates an explosion.</li>
<li><strong>Catalytic Lens</strong>: right-click creates a larger, incendiary explosion.</li>
<li><strong>Mercurial Eye</strong>: right-click shows your current EMC.</li>
<li><strong>Archangel's Smite</strong>: the original's bow component.</li>
</ul>

<h3>Notes</h3>
<blockquote>Still missing: the Transmutation Table/Tablet, Interdiction Torch and the Dark/Red Matter furnaces (blocks).</blockquote>
