<h2>v1.3.0-beta.3 - Matter Furnace (Phase 5.1)</h2>

<h3>Beta Release: Dark & Red Matter Furnaces</h3>
<p>Equivalent Legacy v1.3.0-beta.3 introduces the <strong>Matter Furnace system</strong> — furnaces powered by EMC instead of traditional fuel, completing the core alchemical crafting loop.</p>

<h3>Phase 5.1: Matter Furnace ✅</h3>

<h4>New Features</h4>
<ul>
<li><strong>Dark Matter Furnace (DM Furnace)</strong>
  <ul>
  <li>Smelt items using EMC from Klein Star</li>
  <li>Standard EMC cost multiplier</li>
  <li>19 inventory slots (1 fuel + 9 input + 9 output)</li>
  </ul>
</li>
<li><strong>Red Matter Furnace (RM Furnace)</strong>
  <ul>
  <li>More efficient smelting — 80% of normal EMC cost</li>
  <li>Same slot layout as Dark Matter Furnace</li>
  <li>Faster crafting progression</li>
  </ul>
</li>
<li><strong>EnumMatterType</strong>
  <ul>
  <li>Dark Matter: tier 0, efficiency 14, attack 3</li>
  <li>Red Matter: tier 1, efficiency 16, attack 4</li>
  <li>Charge modifiers for future tool upgrades</li>
  </ul>
</li>
<li><strong>Integration</strong>
  <ul>
  <li>Klein Stars in fuel slot recognized via IItemEmcHolder capability</li>
  <li>EMC cost calculated from item registry values (EMCMappingHandler)</li>
  <li>Redstone output support (future UI enhancement)</li>
  <li>Custom GUIs with progress indicators and EMC display</li>
  </ul>
</li>
</ul>
