<h3>Phase 1B: EMC Registry System (Complete Port) ✅</h3>
<p>The EMC Registry is the <strong>heart of Equivalent Legacy</strong>. It handles all value lookups, calculations, and conversions.</p>

<ul>
<li><strong>Subsystem 1: Hardcoded EMC Values</strong> (235+ items)
  <ul>
  <li>oak_log = 2</li>
  <li>diamond = 2048</li>
  <li>iron_ingot = 256</li>
  <li>netherite_ingot = 8192</li>
  <li>Complete coverage: raw materials, ores, gems, tools, armor, mob drops, EL-specific items</li>
  </ul>
</li>

<li><strong>Subsystem 2: EMCMappingHandler</strong> (Central Coordinator)
  <ul>
  <li>Priority-based resolution: FixedValues > RecipeMappers > ComponentEnhancers > SpecialMappers</li>
  <li>Thread-safe singleton with caching + invalidation</li>
  <li>Public API: getEMCValue(ItemStack), getBaseEMCValue(NSS), getEMCValue(Fluid/TagKey)</li>
  </ul>
</li>

<li><strong>Subsystem 3: DataComponentMapper</strong> (8 Processors)
  <ul>
  <li>EnchantmentProcessor: Enchanted items + bonus EMC per level</li>
  <li>DamageProcessor: Damaged items lose EMC proportional to damage</li>
  <li>ContainerProcessor: Containers include contents EMC</li>
  <li>Plus 5 more: SimpleContainerProcessor, PersistentComponentProcessor, ArmorTrimProcessor, BundleProcessor, WrittenBookProcessor</li>
  </ul>
</li>

<li><strong>Subsystem 4: Special Mappers</strong> (4 Mappers)
  <ul>
  <li>OreBlacklistMapper: Ores = 0 EMC (prevents circular loops)</li>
  <li>RawMaterialsBlacklistMapper: Raw materials excluded</li>
  <li>CustomConversionMapper: Player-defined conversions (public API)</li>
  <li>TagMapper: Tag grouping placeholder (Phase 2 expansion)</li>
  </ul>
</li>

<li><strong>Subsystem 5: Capabilities & Public API</strong>
  <ul>
  <li>IEmcStorage: EMC storage for Klein Stars, Collectors, Condensers</li>
  <li>IKnowledgeProvider: Player transmutation knowledge tracking</li>
  <li>IEmcProvider: Custom EMC providers for addons</li>
  <li>EquivalentLegacyEMCAPI: Public entry point for all EMC queries</li>
  </ul>
</li>
</ul>

<h3>🔧 Technical Architecture</h3>
<ul>
<li><strong>Normalized Simple Stack (NSS)</strong>: All items represented consistently for comparison</li>
<li><strong>BoxedLong Pattern</strong>: 64-bit EMC split into high/low ints for network sync</li>
<li><strong>Priority Resolution</strong>: Multiple mappers handled via priority chain (no conflicts)</li>
<li><strong>Thread Safety</strong>: Synchronized blocks + volatile fields for concurrent queries</li>
<li><strong>Performance</strong>: Caching + lazy remapping minimizes recalculation</li>
</ul>
