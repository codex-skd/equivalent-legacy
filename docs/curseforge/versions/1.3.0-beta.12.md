<h2>🐛 Bug Fix: Missing Item Models (MC 26.2 Item Model System)</h2>

<p>Fixed 9 items that reported <code>Missing item model for location</code> warnings during resource loading. In Minecraft 26.2, items require a definition file under <code>assets/equivalent_legacy/items/</code> in addition to the classic <code>models/item/</code> JSONs.</p>

<h3>Root Cause</h3>
<p>These items had item models but were missing the new-format item definition file, so the game fell back to a missing/broken model:</p>
<ul>
<li><code>pedestal</code></li>
<li><code>dm_pedestal</code></li>
<li><code>rm_pedestal</code></li>
<li><code>destruction_catalyst_block</code></li>
<li><code>transmutation_stone</code></li>
<li><code>pe_axe</code></li>
<li><code>pe_pickaxe</code></li>
<li><code>pe_saw</code></li>
<li><code>spawner_control_wand</code></li>
</ul>

<h3>Fix</h3>
<p>Added the 9 missing definition files under <code>assets/equivalent_legacy/items/</code> following the mod's convention: blocks reference <code>equivalent_legacy:block/&lt;id&gt;</code>, items reference <code>equivalent_legacy:item/&lt;id&gt;</code>. Textures and inventory rendering now load correctly.</p>
