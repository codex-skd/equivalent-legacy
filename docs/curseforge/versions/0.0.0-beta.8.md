<h2>v0.0.0-beta.8 - Alchemical Fuel Chain and Red Matter</h2>

<p>The classic Equivalent Exchange fuel chain arrives, along with the second tier of matter.</p>

<h3>Added</h3>
<ul>
<li><strong>Alchemical Coal</strong>: coal (x4) + Philosopher's Stone. 1,024 EMC.</li>
<li><strong>Mobius Fuel</strong>: Alchemical Coal (x4) + Philosopher's Stone. 3,072 EMC.</li>
<li><strong>Aeternalis Fuel</strong>: Mobius Fuel (x4) + Philosopher's Stone. 9,216 EMC.</li>
<li><strong>Red Matter</strong>: Aeternalis Fuel (x8) around Dark Matter. 417,792 EMC.</li>
</ul>

<h3>Changes</h3>
<ul>
<li><strong>Original recipes restored</strong>: Dark Matter now uses 8 Aeternalis Fuel around a Diamond Block, and Klein Star Ein uses 8 Mobius Fuel around a Diamond — the vanilla substitutes from beta.7 are gone.</li>
</ul>

<h3>Notes</h3>
<blockquote>Still early development. No collectors/condensers/relays, tools/armor, alchemical bags/chest, storage blocks, or Curios support yet.</blockquote>
