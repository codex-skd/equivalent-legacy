<h2>v0.0.0-beta.2 - JEI dependency range fix</h2>

<p>Maintenance beta for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong>. One metadata fix, no gameplay or code changes.</p>

<h3>Fixed</h3>
<ul>
<li><strong>JEI optional dependency range.</strong> <code>neoforge.mods.toml</code> declared the JEI dependency as <code>versionRange="[30.15.0,)"</code> &mdash; a bound carried over from a newer-Minecraft template. JEI for 1.21.1 uses the <code>19.x</code> line, so a normal install failed the check and NeoForge logged <code>Unsupported installed optional dependencies: Mod ID: 'jei' ... Expected range: '[30.15.0,)'</code>. The range is now <code>[19.50.0.414,)</code> (the JEI build shipped by the target modpack, or newer). JEI stays <strong>optional</strong>; the mod loads and works without it.</li>
</ul>

<h3>Notes</h3>
<blockquote>Beta. <code>./gradlew build</code> OK. Same code as beta.1; only the JEI dependency bound in <code>neoforge.mods.toml</code> changed. Not verified in-game.</blockquote>
