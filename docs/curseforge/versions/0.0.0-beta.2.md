<h2>v0.0.0-beta.2 - EMC core system</h2>

<p>First functional milestone: the core EMC (Energy-Matter-Currency) system is now in place, ported from Equivox/ProjectE. No player-facing content yet (no items, GUI, or commands) — this lays the foundation for the transmutation gameplay coming in the next betas.</p>

<h3>Added</h3>
<ul>
<li><strong>Config framework</strong>: <code>CommonConfig</code>, <code>ClientConfig</code>, <code>ServerConfig</code>, <code>MappingConfig</code> via NeoForge <code>ModConfigSpec</code>.</li>
<li><strong>NSS (NormalizedSimpleStack)</strong>: item identification system for EMC, including data-component-aware variants.</li>
<li><strong>EMC mapper</strong>: <code>MappingCollector</code>, <code>SimpleGraphMapper</code>, <code>LongArithmetic</code> for building the EMC value graph.</li>
<li><strong>EMC values</strong>: <code>FixedValues</code> and <code>CustomConversion</code> for value overrides, <code>EMCHelper</code> as the runtime API.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Removed the leftover NeoForge MDK skeleton example item/block and the old <code>Config.java</code>.</li>
</ul>

<h3>Notes</h3>
<blockquote>Still early development. No items, blocks, commands, networking, or GUI yet — those are planned for the next beta releases.</blockquote>
