<h2>v0.0.0-beta.5 - Transmutation GUI</h2>

<p>The Philosopher's Stone is now interactive: right-click it to open the transmutation screen.</p>

<h3>Added</h3>
<ul>
<li><strong>Transmutation GUI</strong>: scrollable list of known items sorted by EMC, current player EMC visible, input slot to learn new items, output slot for transmuted items.</li>
<li>Learn an item by placing it in the input slot; transmute a known item by clicking it in the list (spends EMC server-side).</li>
</ul>

<h3>Fix</h3>
<ul>
<li><strong>Double EMC charge</strong>: transmuting an item charged EMC twice (once on transmute, again on picking up the result), silently requiring 2x EMC. Now charged once.</li>
</ul>

<h3>Notes</h3>
<blockquote>Still early development. No other toolchain items (Dark Matter, Klein Star, collectors) or commands yet.</blockquote>
