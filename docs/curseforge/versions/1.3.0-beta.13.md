<h2>v1.3.0-beta.13 - Full Re-port from the Equivox Reference</h2>

<p>This is a major internal rewrite: the mod has been mechanically re-ported from the up-to-date Equivox 26.2 reference (the fork this mod is based on) to bring its systems, blocks, GUIs, and mechanics into 1:1 parity, replacing the previous partial implementation.</p>

<blockquote>Worlds should remain compatible — mod id, main package, and item/block ids are unchanged. As with any large internal rewrite, back up your world before updating.</blockquote>

<h3>Rewritten Systems</h3>
<ul>
<li><strong>EMC system</strong>: replaced the previous simplified value table with the reference's full mapping/arithmetic engine (BigFraction-based calculation).</li>
<li><strong>Block entities &amp; GUIs</strong>: Collector, Condenser, Furnaces, Alchemical Chest, Pedestals, and Transmutation Table now match the reference's mechanics and rendering, including previously missing progress-bar overlays.</li>
<li><strong>Networking</strong>: packet layer rebuilt to match the reference's structure.</li>
<li><strong>JEI / WTHIT integrations</strong>: recipe categories and tooltips ported and updated for the JEI version this mod targets.</li>
</ul>

<h3>Fixes</h3>
<ul>
<li><strong>Fixed a crash when opening a Collector or Relay</strong> (<code>ArrayIndexOutOfBoundsException</code>) caused by mismatched inventory sizes for higher tiers.</li>
<li><strong>Fixed items disappearing from the Transmutation Table</strong> when closing its GUI with items still in the input/output slots.</li>
<li><strong>Fixed the mod display name</strong> rendering without a space ("EquivalentLegacy") in the creative tab and various tooltips — now reads "Equivalent Legacy".</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>PECore</code> is now the mod's <code>@Mod</code> entry point.</li>
<li>Added the <code>commons-math3</code> dependency, required by the EMC arithmetic system.</li>
<li>Added the reference's Access Transformer (<code>accesstransformer.cfg</code>).</li>
<li>CraftTweaker, Jade, TheOneProbe, and EMI integrations are excluded from this build (no configured dependency) — JEI and WTHIT remain fully supported.</li>
</ul>
