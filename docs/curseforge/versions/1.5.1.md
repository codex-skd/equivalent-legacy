<h2>v1.5.1 - Break-Drop Fix Completed</h2>

<h3>Fix</h3>
<ul>
<li><strong>Condenser (MK1/MK2), Entropy Sink (all tiers), Relay (MK1/MK2/MK3) and the Alchemical Chest still lost their inventory on break</strong>: the 1.5.0 fix moved inventory drops to <code>BlockEntity#preRemoveSideEffects</code> for Collector, Pedestal and Matter Furnace, but missed these remaining item-holding block entities. Breaking any of them still silently lost their contents. The same <code>preRemoveSideEffects</code> override has now been added to <code>CondenserBlockEntity</code> (input/output), <code>EntropySinkBlockEntity</code> (inventory), <code>RelayMK1BlockEntity</code> (input/output) and <code>AlchBlockEntityChest</code> (inventory), dropping every non-empty slot into the world right before the block entity is removed.</li>
<li><strong>Technical note</strong>: <code>CondenserBlockEntity</code> (MK1) uses the same handler instance for both input and output by default (<code>createOutput()</code> returns <code>inputInventory</code>) — the fix guards against dropping that shared handler twice. <code>CondenserMK2BlockEntity</code> overrides both with separate handlers and is unaffected by the guard.</li>
</ul>
