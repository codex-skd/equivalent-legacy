<h2>v1.2.0-beta.7 - Phase 2.4b ChestRenderer Full Implementation</h2>

<h3>Added</h3>
<ul>
<li><strong>ChestRenderer Full</strong>: Alchemical Chest now animates smoothly when opened/closed; the lid rotates 0° (closed) to 90° (open) over 5 ticks using the new <code>LidBlockEntity</code> interface</li>
<li><strong>LidBlockEntity Support</strong>: <code>AlchemicalChestBlockEntity</code> now implements <code>LidBlockEntity</code> with an <code>openNess</code> field (0-5 int) and getter for smooth interpolation</li>
<li><strong>Menu State Sync</strong>: <code>ChestMenu</code> syncs <code>openNess</code> to client via <code>ContainerData</code> for seamless lid animation in single-player and multiplayer</li>
</ul>

<h3>Technical Details</h3>
<ul>
<li><strong>NeoForge 26.2</strong>: Uses the new <code>BlockEntityRenderer&lt;T,S&gt;</code> pipeline with <code>createRenderState</code>, <code>extractRenderState</code>, and <code>submit</code> methods</li>
<li><strong>LidBlockEntity API</strong>: <code>AlchemicalChestBlockEntity.getOpenNess(float partialTick)</code> returns interpolated value (0.0F=closed, 1.0F=open) for smooth client-side animation</li>
<li><strong>State Synchronization</strong>: Server tracks <code>openNess</code> (0-5) and syncs to client via menu data slots; client receives updated state each tick</li>
<li><strong>Rendering</strong>: <code>ChestRenderer</code> extracts <code>openNess</code>, multiplies by 90° to get lid rotation angle, and rotates the chest lid model on the X-axis</li>
</ul>

</ul>
