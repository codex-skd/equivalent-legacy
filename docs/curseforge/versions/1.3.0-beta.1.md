<h2>v1.3.0-beta.1 - Transmutation GUI Improvements & Phase 3</h2>

<h3>Beta Release: Phase 3 GUI Enhancements</h3>
<p>Equivalent Legacy v1.3.0-beta.1 introduces the first phase of v1.3 development: <strong>improved transmutation interface</strong> with better cost visualization and localization.</p>

<h3>Phase 3: Transmutation GUI Improvements ✅</h3>

<h4>What's New</h4>
<ul>
<li><strong>TransmutationScreen Enhanced</strong>
  <ul>
  <li>Per-item EMC cost indicators (green = affordable, red = insufficient)</li>
  <li>Dark overlay on unaffordable items (visual clarity)</li>
  <li>Localized labels for input, output, and EMC display</li>
  <li>Scrollable item list (9 items per page)</li>
  </ul>
</li>
<li><strong>Localization Expansion</strong>
  <ul>
  <li>7 new gui.equivalent_legacy.transmutation keys</li>
  <li>Full translations across 19 languages</li>
  <li>Better player guidance in transmutation UI</li>
  </ul>
</li>
</ul>
