<h2>v0.0.0-beta.19 - Tool Charge/AOE System</h2>

<p>The iconic ProjectE charge system arrives for the matter toolchain.</p>

<h3>Added</h3>
<ul>
<li><strong>Charge levels</strong>: shift-right-click cycles a 0-3 charge on Swords, Pickaxes and Hammers (shown in the tooltip).</li>
<li><strong>Area mining</strong>: Hammers and Pickaxes now mine a growing area aligned to the face you break (radius scales with charge), with proper item drops and durability.</li>
<li><strong>Area attacks</strong>: Swords (including Katar and Morning Star) damage nearby mobs in a radius scaled by charge.</li>
</ul>

<h3>Notes</h3>
<blockquote>Charge behavior is applied to swords/pickaxes/hammers; axes, shovels, hoes and shears remain uncharged for now. The world-level EMC network is still not implemented (machines only link to adjacent blocks).</blockquote>
