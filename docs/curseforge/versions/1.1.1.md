<h2>v1.1.1 - EMC System Fix</h2>

<p>Patch release: fixes the Transmutation Table to work with vanilla items.</p>

<h3>Fixed</h3>
<ul>
<li><strong>Transmutation Table learning</strong>: now initializes with base vanilla item EMC values (coal, stone, ores, gems, nether_star), enabling the table to learn from and transmute vanilla objects correctly.</li>
<li>The EMC system now properly initializes base values using ProjectE's standard seed, providing a foundation for transmutation recipes.</li>
<li>Infrastructure added for full recipe-based EMC graph calculation (deferred for future expansion with proper NeoForge recipe API integration).</li>
</ul>
