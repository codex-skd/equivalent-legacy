<h2>v0.0.0-beta.13 - Curios Klein Stars</h2>

<p>All six Klein Star tiers can now be worn as a Curios trinket.</p>

<h3>Added</h3>
<ul>
<li><strong>Curios support</strong>: Klein Star Ein through Omega are equippable in a dedicated <code>klein_star</code> Curios slot when <a href="https://www.curseforge.com/minecraft/mc-mods/curios">Curios</a> is installed. Wear a star to carry EMC hands-free.</li>
<li>Implemented as a data-driven soft dependency (tags + slot definitions), so no Curios dependency is required to run the mod.</li>
</ul>

<h3>Notes</h3>
<blockquote>Only Klein Stars are equippable for now — the rings, amulets and talismans from the original toolchain don't exist in this port yet.</blockquote>
