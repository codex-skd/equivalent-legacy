<h2>v0.0.0-beta.18 - Transmutation Table/Tablet and Interdiction Torch</h2>

<p>The portable and stationary transmutation terminals, plus a defensive torch.</p>

<h3>Added</h3>
<ul>
<li><strong>Transmutation Table</strong>: a block that opens the full transmutation GUI (learn items, transmute with EMC).</li>
<li><strong>Transmutation Tablet</strong>: the portable version of the table, opened with a right-click anywhere.</li>
<li><strong>Interdiction Torch</strong>: pushes hostile mobs away from a 4-block radius.</li>
</ul>

<h3>Notes</h3>
<blockquote>The Dark/Red Matter furnaces and colored gem armor remain as possible future additions; the core ProjectE feature set is now complete.</blockquote>
