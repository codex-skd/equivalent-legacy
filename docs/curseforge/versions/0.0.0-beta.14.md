<h2>v0.0.0-beta.14 - Covalence Dusts and Tome of Knowledge</h2>

<p>The crafting foundation of the mod arrives, plus the ultimate knowledge unlock.</p>

<h3>Added</h3>
<ul>
<li><strong>Low / Medium / High Covalence Dust</strong>: crafted from charcoal + cobblestone, iron + redstone, and diamond + coal (40 dust per craft). Used in the chest/bag and many toolchain recipes.</li>
<li><strong>Tome of Knowledge</strong>: right-click to instantly learn every transmutable item in the game (consumed on use).</li>
</ul>

<h3>Changes</h3>
<ul>
<li><strong>Original recipes restored</strong>: the Alchemical Chest and Bag now use covalence dusts instead of the alchemical-fuel substitutes from earlier betas.</li>
</ul>

<h3>Notes</h3>
<blockquote>Still missing: the arcana rings/amulets/talismans, colored bags, transmutation table/tablet, nova items, furnaces and the remaining toolchain behaviors.</blockquote>
