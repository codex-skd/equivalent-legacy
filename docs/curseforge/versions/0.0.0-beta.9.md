<h2>v0.0.0-beta.9 - Storage Blocks and Item Render Fix</h2>

<p>Solid storage blocks for the fuels and both matters, plus a rendering fix that makes every item visible again.</p>

<h3>Added</h3>
<ul>
<li><strong>Alchemical Coal Block</strong>, <strong>Mobius Fuel Block</strong>, <strong>Aeternalis Fuel Block</strong> (9 items each), <strong>Dark Matter Block</strong> and <strong>Red Matter Block</strong> (4 items each) with craft/deconstruct recipes and matching EMC values.</li>
<li>Blocks have full blockstates, models, loot tables and appear in the creative tab.</li>
</ul>

<h3>Fixes</h3>
<ul>
<li><strong>Item model bindings</strong>: Minecraft 26.2 requires <code>assets/&lt;namespace&gt;/items/&lt;id&gt;.json</code> bindings for every item to render. These were missing, so all mod items were rendering with the missing-model placeholder. All items (Philosopher's Stone, fuels, matters, Klein Stars, blocks) now render correctly.</li>
</ul>

<h3>Notes</h3>
<blockquote>Still early development. No collectors/condensers/relays, tools/armor, alchemical bags/chest, or Curios support yet.</blockquote>
