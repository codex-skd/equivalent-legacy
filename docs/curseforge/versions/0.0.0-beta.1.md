<h2>v0.0.0-beta.1 - Port to Minecraft 1.21.1</h2>

<p>First beta of Equivalent Legacy for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong> (Java 21). API port of the stable 26.2 line (1.6.4) &mdash; the fork's own adaptations are preserved; only 26.2-only Minecraft / NeoForge API was reverted to its 1.21.1 form.</p>

<h3>About this build</h3>
<ul>
<li><strong>API port</strong> of the 26.2 source (474 classes) to the 1.21.1 API: <code>Identifier</code> &rarr; <code>ResourceLocation</code>; the 26.2 unified transfer API &rarr; 1.21.1 <code>neoforge.items</code>/<code>fluids</code>/<code>energy</code> capabilities; <code>Item.appendHoverText</code> reverted to the 4-arg form (no <code>TooltipDisplay</code>); <code>Item.use</code> &rarr; <code>InteractionResultHolder&lt;ItemStack&gt;</code>; the 1.21.1 recipe / serializer API; custom <code>DeferredRegister</code> / <code>DeferredHolder</code> layer; <code>MobSpawnType</code>, <code>UseAnim</code>, <code>AddReloadListenerEvent</code>, permission-level constants, and ~30 more reversions.</li>
<li><strong>Fixed</strong> (regression caught during the port): breaking a Collector, Relay, Condenser, Matter Furnace, Pedestal, Entropy Sink or Alchemical Chest voided its stored items instead of dropping them. 26.2 used the <code>BlockEntity#preRemoveSideEffects</code> hook, which does not exist in 1.21.1; the inventory drops are now driven from <code>Block#onRemove</code> (which still runs while the block entity is valid).</li>
<li><strong>Fixed</strong>: 151 recipes and 2 tags failed to load &mdash; the 26.2 datapack used bare-string ingredients where 1.21.1 requires <code>{"item": "&hellip;"}</code> / <code>{"tag": "&hellip;"}</code>. All recipe JSON re-encoded; two tags had references to items that do not exist in 1.21.1 removed.</li>
<li><strong>Dependency</strong>: Regalia Slots API (the team's own fork of the Curios API), not Curios.</li>
</ul>
