<h2>v0.0.0-beta.22 - Dark and Red Matter Furnaces</h2>

<p>The last blocks from the original mod: fast smelting furnaces.</p>

<h3>Added</h3>
<ul>
<li><strong>Dark Matter Furnace</strong>: smelts and burns fuel 4x faster than a vanilla furnace.</li>
<li><strong>Red Matter Furnace</strong>: 8x faster (upgraded from the Dark Matter furnace).</li>
<li>Both use vanilla smelting recipes, a vanilla-style furnace GUI, and save their contents across reloads.</li>
</ul>

<h3>Notes</h3>
<blockquote>This completes the full block set of the original mod. Remaining known gaps are refinements only: arcana passive effects from Curios slots (they currently work from the inventory), and persisting the in-memory EMC network pool between saves.</blockquote>
