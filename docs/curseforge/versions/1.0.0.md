<h2>v1.0.0 - First stable release (Minecraft 1.21.1)</h2>

<p>First stable release of Equivalent Legacy for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong>
(Java 21). It consolidates the <code>0.0.0-beta.1</code> &rarr; <code>0.0.0-beta.4</code> line with
no further code changes. This build has been running in a full modded-server pack.</p>

<h3>What the 1.21.1 line brought</h3>
<ul>
<li><strong>API port of the stable 26.2 line (1.6.4)</strong>, 474 classes. The fork's own
adaptations are preserved; only 26.2-only Minecraft / NeoForge API was reverted to its 1.21.1 form,
using upstream ProjectE 1.21.1 as the API reference. Requires <strong>Regalia Slots API</strong>
(the team's fork of the Curios API), not Curios.</li>
<li><strong>Item-loss fix</strong>: breaking a Collector, Relay, Condenser, Matter Furnace, Pedestal,
Entropy Sink or Alchemical Chest no longer voids its stored contents (reverting the 26.2-only
<code>preRemoveSideEffects</code> hook to a 1.21.1 <code>Block#onRemove</code> +
<code>dropContentsOnRemoval(&hellip;)</code> path).</li>
<li><strong>Recipe / tag fix</strong>: 161 recipe JSONs and 2 tags re-encoded from the 26.2
bare-string datapack format to the 1.21.1 object form (151 recipes + 2 tags had failed to load).</li>
<li><strong>Client assets</strong>: added the 19 missing block-item models, so alchemical-fuel
blocks, Collector MK1&ndash;3, Entropy Sink, Stellar Condenser, matter furnaces/blocks, Nova
Catalyst/Cataclysm and Relay MK1&ndash;3 render correctly instead of the missing-texture
checkerboard.</li>
<li><strong>JEI range</strong> fixed to the 1.21.1 <code>19.x</code> line; JEI stays optional.</li>
<li><strong>Conditional custom conversions</strong>: <code>pe_custom_conversions</code> files now
honour <code>neoforge:conditions</code>; the bundled ATM/Powah EMC compat is split and gated on
<code>allthemodium</code> / <code>powah</code>, removing the "Unable to deserialize key" ERROR spam
on packs without those mods. EMC values unchanged.</li>
</ul>

<h3>Notes</h3>
