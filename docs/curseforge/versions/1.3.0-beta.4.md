<h2>v1.3.0-beta.4 - Alchemical Chests (Phase 5.2)</h2>

<h3>Beta Release: Advanced Storage with EMC Sync</h3>
<p>Equivalent Legacy v1.3.0-beta.4 introduces <strong>Alchemical Chests</strong> — massive 104-slot storage containers that integrate with the EMC system for advanced inventory management.</p>

<h3>Phase 5.2: Alchemical Chests ✅</h3>

<h4>New Features</h4>
<ul>
<li><strong>Alchemical Chest Storage</strong>
  <ul>
  <li>104-slot inventory (8 rows × 13 columns)</li>
  <li>Fits in compact space with 14-block height</li>
  <li>Direction-aware placement (FACING property)</li>
  <li>Waterloggable (can place in water)</li>
  </ul>
</li>
<li><strong>EMC Integration</strong>
  <ul>
  <li>10,000,000 EMC storage capacity</li>
  <li>IEmcStorage capability for EMC network queries</li>
  <li>Compatible with Collectors, Condensers, Transmutation</li>
  </ul>
</li>
<li><strong>User Interface</strong>
  <ul>
  <li>Large 256×256 GUI for 8×13 grid display</li>
  <li>Player inventory below chest slots</li>
  <li>Lid animation (opens/closes when accessing)</li>
  <li>Localized in 19 languages</li>
  </ul>
</li>
<li><strong>Advanced Placement</strong>
  <ul>
  <li>Respects player-facing direction on placement</li>
  <li>Works in any orientation (water-compatible)</li>
  <li>Custom collision shape (no full-block collision)</li>
  </ul>
</li>
</ul>
