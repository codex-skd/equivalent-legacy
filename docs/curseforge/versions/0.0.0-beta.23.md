<h2>v0.0.0-beta.23 - Persistent EMC Network</h2>

<p>The machine EMC pool now survives server restarts.</p>

<h3>Changed</h3>
<ul>
<li><strong>Persistent pools</strong>: each dimension's EMC network is stored as <code>SavedData</code> and loaded on server start / saved on server stop. Collectors, relays and condensers keep their shared EMC across restarts.</li>
</ul>

<h3>Notes</h3>
<blockquote>The only remaining known gap is the arcana passive effects activating from Curios slots (they currently apply from the inventory); that requires the Curios API as a compile-time dependency.</blockquote>
