<h1 align="center">Equivalent Legacy</h1>
<p align="center">Bring back the EMC. Transmute anything.</p>

<hr>

<h2>Overview</h2>
<p>Equivalent Legacy brings the classic Equivalent Exchange-style gameplay to modern Minecraft (26.2 / NeoForge): assign an EMC (Energy-Matter-Currency) value to items, transmute them into each other, and progress through the Philosopher's Stone toolchain.</p>
